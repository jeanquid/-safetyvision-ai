# Digesto Prevención 4.0 - Normativas SRT Argentina

<!-- chunk-id: res-srt-48-25-art-1 -->
## Resolución SRT 48/2025 - Creación del Ecosistema de Prevención 4.0
Crea formalmente el Ecosistema Digital de Prevención 4.0 de la República Argentina con el fin de digitalizar, securizar y centralizar las actas de inspección laboral, auditorías de higiene y seguridad y constancias de cumplimiento. Exige el uso de mecanismos criptográficos de inmutabilidad y firma para garantizar la validez legal del registro e impedir repudio.

<!-- chunk-id: disp-srt-15-26-anexo-trazabilidad -->
## Disposición SRT 15/2026 - Pautas de Trazabilidad y Evidencia
Determina las especificaciones técnicas obligatorias para las plataformas del ecosistema Prevención 4.0, incluyendo la generación de cadenas criptográficas encadenadas (hash chaining) para todas las modificaciones, el sellado unívoco del hash de evidencia fotográfica asociada y la disponibilidad de un endpoint de validación pública mediante código QR.
